A city pigeon pitches its startup to investors in a single line: a breadcrumb-delivery empire run by a flock of ten thousand couriers who already own every park bench in the city.

## Run it

```sh
node main.ts
```

It writes exactly one line (131 characters, no trailing newline) to `/output/entry.txt`, deterministically — the same bytes on every run.
